Markup, Viewer & Plan Room is a shared viewing and annotation layer for PDFs, drawings and site photos. A three-pane viewer gives you the file list, a canvas with markup tools, and a side panel for comments, versions and approval. Photos open straight into markup.

The **plan room** overlays defect, photo and inspection pins on a drawing page with layer toggles, and pins link to the asset they relate to — so selecting an asset on a drawing opens its inspection history. Markups are kept as data against the file version, so the original file is never altered; a sealed, flattened copy is only produced on approval, publication or transmittal.

## Key features

- Viewer with cloud, arrow, text, dimension, freehand and stamp tools
- Stamp library (approved, rejected, custom), with stamps showing who, when and the document fingerprint
- Scale calibration for on-drawing measurements
- Photo markup with pins, arrows and text, before-and-after pairing, and location data stripped by default
- Markup threads with open and resolved status and comments
- Plan room pins for defects, photos, inspections and notes, with layer toggles and filters by area, date and status
- Asset pins linking a drawing location to the asset register
- Inspection finding pins coloured by severity for coating and CUI condition maps
- Revision overlay comparison, with pins carried forward or flagged for review
- Offline drawing sets cached per scope, syncing annotations later
- Sealed, stamped export on approval while the source file stays unchanged
