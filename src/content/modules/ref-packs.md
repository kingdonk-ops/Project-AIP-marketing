Regional Reference Packs supply the region-specific content your projects rely on — standards and code lists, cost references, currencies, tax rates and jurisdiction defaults — as selectable data rather than custom configuration.

Enable the packs you need and their content appears as pick-lists and references across the platform. Packs are versioned, and each project pins a version, so existing records keep pointing at the standard revision that was in force when the work was done. Where reference content is licensed, you load your own licensed data and it stays within your organisation.

## Key features

- Standards and code lists per region, such as AS/NZS, ISO, API and ASTM references
- Standards linked to ITP checklist items and acceptance criteria, so inspectors can cite the governing clause
- Currencies and tax rates per region
- Exchange rate source and effective date captured on each priced record
- Import and enable packs per organisation
- Customer-loaded licensed content with a licence flag and no sharing between organisations
- Pack versioning with versions pinned per project and an upgrade preview
- Regional vocabulary and jurisdiction packs bundling terminology, tax, public holidays and date and number formats
