Organisations & Data Residency is how the platform keeps customers apart and decides where their data lives. Each customer has its own isolated space, and inside it you can set up client, owner and subcontractor organisations, projects, teams and asset scopes. Separation is enforced at the data level, designed so one customer's records can't appear in another's.

Client organisations can share an asset record without seeing each other's commercial data — a client sees status and evidence, not your rates. Data stays in-region, with Australian hosting first and further regions planned, and customers with stricter needs can be served from a dedicated deployment built from the same product.

## Key features

- Isolated data space for every customer, enforced on every record, file and search index
- Client organisations typed as owner, client or subcontractor
- Shared asset records with party-scoped field visibility, expiry, revoke and preview-as-organisation
- In-region hosting, starting in Australia
- Dedicated deployment option from the same product and release process
- Organisation settings for branding, terminology, enabled modules and retention defaults
- Guided provisioning with region, template pack, terminology set, admin invite and sample data
- Offboarding with full export, legal hold check, secure erasure and a signed deletion certificate
- Customer-approved, time-boxed support access with an on-screen banner and audit entries
- Usage limits per organisation so no customer affects another's performance
