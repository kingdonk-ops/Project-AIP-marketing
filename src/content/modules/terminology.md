Every label, status name and record-type name in the platform is a term you can rename. Call it a Variation, a Change Order or a Client Instruction; a Work Pack or a Campaign; a Defect, a Punch or a Deficiency. Workflow logic runs on stable internal codes underneath, so renaming never changes behaviour.

Overrides layer from the platform default through market, organisation, client and project, so client-specific wording applies only where it should. The same terms flow through screens, emails, PDF reports and exports, and a new market can be set up by importing a terminology pack — no deployment needed.

## Key features

- Every user-facing label, status and record type is a renamable term
- Override chain: platform default, market pack, organisation, client and project
- Admin screen to search, preview and override labels
- Consistent wording across screens, emails, PDF reports and exports
- Importable and exportable terminology packs, with built-in market packs planned
- Pack versioning with diff, dry-run preview and rollback
- Report of untranslated or hard-coded labels so raw terms don't leak into emails and PDFs
- Glossary of standards and abbreviations shown as tooltips, with equivalent concepts mapped per market
- Term aliases in search and import, so "punch" finds "defect" records
- Unit conversion for measurements, with display units per project
