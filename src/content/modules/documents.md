Document Library & Control is the single document store for the platform. Every file is linked to an asset and/or a record — an inspection, issue, RFI, task, submittal or project — so retrieval starts from the thing you are working on, not a folder tree.

Revisions are controlled with one current version and the rest superseded, every change is audited, and files can be found by asset, tag, saved view or **full-text search**, including scanned documents. Where a client requires it, optional ISO 19650-style naming validation and container states can be switched on without changing how the library works.

## Key features

- Upload against an asset, inspection, issue or project, with type, title, revision, metadata and previews
- Bulk upload with file-name parsing, auto-naming from templates and duplicate detection
- Revision control with promote-to-current, restore, compare and download of any version
- Tags, favourites, pins and personal or shared saved views
- Cross-references to RFIs, issues, inspections, tasks and submittals
- Full-text search across documents, including text read from scans
- Distribution lists and subscriptions, with notification on new revisions
- Required source-documents register and a gate that holds work until they are received
- Documents tab on each asset, with an optional view of child assets, plus photo galleries per asset and inspection
- Controlled-copy watermark stamping user, time and revision on download or print
- Recycle bin with retention window and legal hold
- Optional ISO 19650-style naming, container states and suitability codes, with a client-configurable document register export
