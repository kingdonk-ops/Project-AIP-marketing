The report engine turns structured inspection, diary and meeting data into PDF reports, certificates and signed records — without re-typing results into a word processor.

Each issued report is pinned to the template and data version that produced it, so it can be reproduced exactly years later.

## Highlights

- Client-specific branding and numbering schemes
- Pre-flight checks stop reports going out with missing readings or unsigned points
- Report register with search and metadata
