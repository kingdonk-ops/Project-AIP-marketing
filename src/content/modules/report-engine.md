The Report Engine turns structured inspection, diary and meeting data into PDF reports, certificates and signed records. Report templates select sections and map fields to report slots, so one inspection can be issued as an internal report, a client report or a compliance certificate without re-typing anything.

Before a report is generated, a **pre-flight check** runs your rules to stop it going out with missing readings or unsigned points. Reports render in the background in portrait or landscape, with photos, charts, repeating tables and domain-specific blocks such as thickness maps and DFT charts, and land in a searchable report register.

Every issued report is pinned to the template and data version used, so it can be reproduced exactly years later. Publishing signs the record and distributes it to a named list through expiring, authenticated download links with delivery receipts. Corrections are issued as new superseding versions, never as edits.

## Key features

- Report templates with sections, field mapping, styling, orientation, versioning and live-data preview
- Internal, client and certificate variants of the same record
- Automatic generation on approval, configurable per template
- Report pre-flight checks for missing readings and unsigned points
- Photos, charts and repeating tables inlined
- Thickness maps, CUI condition charts and coating DFT charts, including readings against minimum wall and heat maps by grid
- Signature block with name, signature image, date and time
- Issued reports pinned to template and data version, with exact re-rendering
- Client-specific numbering and revision sequences with clear supersession
- Searchable report register
- Publish and distribute signed PDFs to a named list, and republish as a superseding version
- Branding per organisation or client, plus data book compilation with bookmarked index and cover sheets
