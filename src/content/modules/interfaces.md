Interface Management is a register of hand-offs between work packages, contractors and disciplines, including client and subcontractor handovers. Each interface records **who must provide what to whom, by when**, and moves from identified to agreed, delivered and accepted.

Interface points are tied to assets and, where relevant, scope tasks — scaffold handover, insulation strip, coating access, isolation ready — so a late interface shows up as a visible constraint on the work it's blocking. Two-party acceptance with signed attestation and evidence gives defensible proof that a handover happened.

## Key features

- Interface points with provider, receiver, deliverable and need date
- Asset-linked interface points tied to scope tasks
- Interface templates with default providers, receivers and lead times
- Status stages: identified, agreed, delivered, accepted
- Two-party acceptance with signed attestation and evidence (photos, certificates, inspection records)
- Configurable escalation ladder, with escalated items added to the next meeting agenda
- Blocked-by constraints shown on scope tasks and the look-ahead
- Interface matrix by package or contractor, plus ageing and heat-map views
- Party-scoped visibility so each side sees only its own interfaces
- Links to RFIs, submittals and documents
