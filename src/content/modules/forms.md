The Form & Template Designer is the no-code builder behind every checklist, inspection, ITP, permit and test report on the platform. Admins assemble templates from sections and fields, add conditional logic, calculations and validation, and lay them out exactly as the report needs to read.

When a template is ready, it is published as a **frozen revision**. Inspections always keep the revision they started on, so changing a template never rewrites a record already in the field. Logic is written as safe, declarative rules rather than scripts, and behaves the same on the web and on mobile devices.

It is built for real engineering inspections — coating and blasting ITRs, thickness surveys, bolt torque, welding, concrete pours and CUI inspections — where readings are tied to an asset, a calibrated instrument and a qualified signer.

## Key features

- Sections, grid and tabular layouts, with a custom layout per template
- Field types including measurements with units, photos, video, audio, signatures, GPS, QR and barcode, repeating tables and asset, user or document references
- Conditional visibility and required rules with a visual condition builder
- Calculated fields such as DFT averages and corrosion rates, using a restricted formula language
- Validation per field and per row in repeating tables
- Template lifecycle from draft to approved to retired, with revision history, cloning, export and import
- Reusable, versioned section and question library for DFT readings, environmental conditions and weld details
- Instrument reference fields that stop readings being recorded with an out-of-calibration gauge
- Context auto-fill for asset tag, scope number, location and procedure
- Test-fill and publish checks that run rules on sample answers and block publishing when they fail
- Print-accurate mapping from fields to the designed report layout
- Import assistant that suggests fields from an existing spreadsheet or PDF, with human review
